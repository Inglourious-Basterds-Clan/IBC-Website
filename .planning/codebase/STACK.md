# Technology Stack

**Analysis Date:** 2026-10-13

## Languages

**Primary:**
- JavaScript (ES modules, `"type": "module"`) - build code (`eleventy.config.js`, `lib/*.js`, `scripts/*.js`, `src/_data/*.js`), tests (`test/*.test.js`) and browser code (`src/js/main.js`, `src/js/modules/*.js`)
- Nunjucks templates (`.njk`) - all pages and partials (`src/*.njk`, `src/_includes/layouts/base.njk`, `src/_includes/partials/*.njk`)
- CSS - single entry `src/css/style.css` with `@import`ed partials in `src/css/partials/`, bundled by Lightning CSS

**Secondary:**
- JSON-LD - generated by `lib/schema.js` (Organization/WebSite, BreadcrumbList, FAQPage)
- XML - `src/sitemap.xml.njk`, IIS config `src/web.config.njk`
- Polish language content only (`site.locale = "pl_PL"` in `src/_data/site.js`)

## Runtime

**Environment:**
- Node.js >= 22.19 (`package.json` `engines`); `.nvmrc` pins `24`
- Output is plain static files in `_site/` - no server runtime in production
- Browser: native ES modules (`<script type="module" src="/js/main.js?v={{ jsHash }}">` in `src/_includes/layouts/base.njk`); CSS targets Chrome/Edge/Firefox 100+, Safari/iOS 15+ (`lib/css.js` `cssTargets`)

**Package Manager:**
- npm
- Lockfile: present (`package-lock.json`; also `tools/seo-images/package-lock.json`)

## Frameworks

**Core:**
- Eleventy (`@11ty/eleventy`) ~3.1.6 (installed 3.1.6) - static site generator; config `eleventy.config.js`, input `src/`, output `_site/`, Nunjucks as HTML/Markdown engine, `HtmlBasePlugin` for `pathPrefix`

**Testing:**
- Node built-in test runner (`node --test "test/*.test.js"`) with `node:assert`; no third-party test framework. Tests build into `_test/`.

**Build/Dev:**
- `@11ty/eleventy-img` 7.0.0 - build-time responsive images (AVIF/WebP/etc.) via `lib/images.js`, cached in `.cache/img/`, copied to `<output>/img/` in an `eleventy.after` hook
- `lightningcss` 1.33.0 - CSS bundling + minification (`lib/css.js`, emitted by `src/css/style.11ty.js`), content hash used as `?v=` cache buster
- `sharp` 0.35.5 - pinned via `overrides` (transitive of eleventy-img); also direct dependency of the one-off `tools/seo-images/make-seo-images.js`
- Custom build scripts: `scripts/clean.js`, `scripts/check-seo.js` (SEO gate, `lib/check-seo.js`), `scripts/check-perf.js` (perf budget gate, `lib/check-perf.js`), `scripts/warm-images.js` (pretest image cache warm)

## Key Dependencies

**Critical:**
- `@11ty/eleventy` ~3.1.6 - whole build pipeline
- `@11ty/eleventy-img` 7.0.0 - every `{% picture %}` shortcode output
- `lightningcss` 1.33.0 - the only stylesheet producer; explicit targets needed to keep `-webkit-backdrop-filter`

**Infrastructure:**
- No runtime npm dependencies (all are `devDependencies`); browser JS uses no libraries
- Icons: inline SVG from `lib/icons.js` (`{% icon %}` shortcode) - no Font Awesome CDN
- Fonts: self-hosted Montserrat variable woff2 `src/fonts/montserrat-latin-ext.var.woff2` + `src/fonts/OFL.txt` (subsetting notes in `tools/fonts/README.md`) - no Google Fonts

## Configuration

**Environment:**
- Single source of site config: `src/_data/site.js` (url, pathPrefix, name, Discord invite, social links, ogImage, indexable)
- `SITE_URL` - origin only; required for `ELEVENTY_RUN_MODE=build` unless `ALLOW_LOCAL_SITE_URL=1`; validated and normalised
- `PATH_PREFIX` - subfolder deploys (e.g. `/IBC-Website/`); Git Bash needs `MSYS_NO_PATHCONV=1`
- `SITE_INDEXABLE=1` - opt-in indexing; requires https and `PATH_PREFIX=/`; otherwise every build is noindex
- `INCLUDE_DEV_PAGES=1` - render `devOnly` pages (`src/_dev/`) in a build
- `DISCORD_FETCH=0` - skip the build-time Discord fetch (`src/_data/discordBadge.js`)
- No `.env` files present

**Build:**
- `eleventy.config.js`, `package.json` scripts (`dev`, `build`, `test`), `.nvmrc`
- Content data: `src/_data/{gallery,join,navigation,operations}.js`; facts tracking in `FACTS.md`

## Platform Requirements

**Development:**
- Node 24 (per `.nvmrc`), `npm ci`, `npm run dev` (eleventy --serve, localhost:8080)

**Production:**
- Any static host. Preview: GitHub Pages via `.github/workflows/pages.yml`. Final target: IIS (`src/web.config.njk` emits `/web.config` with 404 page and MIME maps for `.webmanifest`, `.avif`, `.webp`, `.woff2`), built locally per README cutover checklist.
