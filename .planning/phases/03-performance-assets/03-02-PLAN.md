Facts (research spike, 2026-10-10):
- Upstream source: google/fonts `ofl/montserrat/Montserrat[wght].ttf` (variable, fvar axis `('wght', 100.0, 100.0, 900.0)`) and `ofl/montserrat/OFL.txt` (copyright line "Copyright 2024 The Montserrat.Git Project Authors").
- Subset recipe that produced a 36,460-byte woff2: `pyftsubset Montserrat[wght].ttf --unicodes="U+0000-00FF,U+0100-017F,U+2000-206F,U+20AC,U+2122,U+2190-2193,U+2212" --layout-features='kern,liga,calt,ccmp,locl,mark,mkmk' --flavor=woff2 --output-file=montserrat-latin-ext.var.woff2`. With every layout feature the file grows to 64,712 bytes, so keep the listed features (kerning and Polish diacritic composition).
- Every non-ASCII character the templates and main.js use today lies inside those ranges: – „ ” and ą ć ę ł Ł ń ó Ó ś ź ż Ż.
- The 18 Polish letters: U+0104 Ą, U+0105 ą, U+0106 Ć, U+0107 ć, U+0118 Ę, U+0119 ę, U+0141 Ł, U+0142 ł, U+0143 Ń, U+0144 ń, U+00D3 Ó, U+00F3 ó, U+015A Ś, U+015B ś, U+0179 Ź, U+017A ź, U+017B Ż, U+017C ż.
- WOFF2 layout: 48-byte header (signature "wOF2", numTables uint16 at 12, totalCompressedSize uint32 at 20), then the table directory: per table a flags byte (bits 0-5 known-tag index, 63 = an explicit 4-byte tag follows; bits 6-7 transform version), origLength as UIntBase128, and transformLength as UIntBase128 only when the table is transformed (glyf/loca are transformed when version is 0; every other table when version is not 0). The compressed block follows the directory: one Brotli stream holding all tables back to back in directory order (transformed length where transformed). cmap is never transformed.
- Known-tag table order (index 0..62): cmap head hhea hmtx maxp name OS/2 post cvt fpgm glyf loca prep CFF VORG EBDT EBLC gasp hdmx kern LTSH PCLT VDMX vhea vmtx BASE GDEF GPOS GSUB EBSC JSTF MATH CBDT CBLC COLR CPAL SVG sbix acnt avar bdat bloc bsln cvar fdsc feat fmtx fvar gvar hsty just lcar mort morx opbd prop trak Zapf Silf Glat Gloc Feat Sill (tags with trailing spaces: "cvt ", "CFF ", "SVG ").
- cmap: version uint16, numTables uint16, then encoding records (platformID, encodingID, offset uint32). Use subtables of platform 0 (any encoding) or 3 with encoding 1 or 10. Format 4: segCountX2, then endCode[], reservedPad, startCode[], idDelta[], idRangeOffset[], glyphIdArray (when idRangeOffset is non-zero, the glyph index is read at the idRangeOffset word address + 2·(c − startCode); a non-zero result gets idDelta added mod 65536). Format 12: nGroups uint32 at +12, groups of (startCharCode, endCharCode, startGlyphID) uint32. A code point mapped to glyph 0 is not covered.
- Python 3.14.7 is installed on this machine; fonttools/brotli are not installed globally.
- lib/image-size.js is the house style for a header-only binary parser (comment header, Node built-ins only, input guards).
