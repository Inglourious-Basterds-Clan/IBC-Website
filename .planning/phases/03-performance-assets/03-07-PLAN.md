## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTML attributes -> module loader | `data-js` text selects which code runs |
| build-time attributes -> DOM writes | data-discord-url and data-lightbox-* values are written into the page at runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-SC | Tampering | dependency tree | low | accept | No package installs; native ES modules only |
| T-03-18 | Tampering / Elevation | dynamic import() | high | mitigate | Hook text is only a key into a frozen literal map checked with an own-property test; specifiers are string literals (modules.test.js asserts every import( is followed by a quote); unknown names load nothing |
| T-03-19 | Tampering (DOM XSS) | terminal and easter-egg DOM writes | medium | mitigate | The last HTML-string assignment is replaced by createElement + textContent; a static test fails if any src/js file assigns HTML strings; data-* values go only to textContent, srcset and src properties |
| T-03-20 | Denial of service | a module failing to load | low | accept | A failed import only disables that feature on that page; the hook-to-file test makes sure every hook has its module in the output |
</threat_model>
