- Measured hero sizes at 1280 w: AVIF q50 81 KB, WebP q60 114 KB, JPEG q65 mozjpeg 110 KB.
- eleventy-img 7.0.0: ESM, Node 22+, `import Image from "@11ty/eleventy-img"`; `Image(src, options)` returns `{ avif: [...], webp: [...], jpeg: [...] }`, each entry has `url`, `width`, `height`, `size`, `outputPath`, `srcset`. Output file names are `<hash>-<width>.<format>`. `Image.generateHTML(metadata, attrs)` emits `<picture>` with typed `<source>`s and an `<img>` whose `width`/`height` come from the largest output and `src` from the smallest fallback. It escapes only `alt`; every other attribute is inserted raw.
- Default `formatFiltering: ["transparent", "animated"]` drops JPEG for any source with an alpha channel; pass `formatFiltering: []` (Pitfall 3; two gallery PNGs have an opaque alpha channel).
- eleventy-img skips writing a file that already exists in `outputDir` (disk cache), so a warm `.cache/img` makes later builds read-only.
- `eleventyConfig.addShortcode(name, fn)` routes an `async function` to `addAsyncShortcode`; a plain function is a sync universal shortcode (async shortcodes break inside Nunjucks `{% for %}`/macros).
- `eleventy.after` receives `{ directories, … }`; `directories.output` respects the tests' `--output=_test/<name>`.
- HtmlBasePlugin rewrites only `a/link[href]`, `img[src,srcset]`, `source[src,srcset]`, `script[src]` and a few others. It does NOT rewrite `<link imagesrcset>` or any `data-*` attribute: those go through the `htmlBaseUrl` filter, exactly once (applying it to `img`/`source` URLs double-prefixes).
- Today's hero rule (src/css/style.css, HERO SECTION): `.hero-image-bg { position: absolute; top: 0; left: 0; width: 100%; height: 100%; background-image: linear-gradient(rgba(8, 14, 17, 0.35), rgba(8, 14, 17, 0.75)), url('../assets/hero-bg.jpg'); background-size: cover; background-position: center; z-index: -1; }`. That url() is the only url() in the stylesheet.
- head.njk already sets `isHome` (`page.url == "/"`) at the top; the stylesheet block sits under the `<!-- Stylesheets & Preconnect -->` comment.
- `.gitignore` already ignores `.cache/`.
- sharp 0.35.5 was vetted by the user in quick task 261008-vmd (tools/seo-images pins it); the orchestrator asked only to confirm the resolved version, so this plan has no install checkpoint. `@11ty/eleventy-img` 7.0.0 is approved by the package legitimacy audit (OK, no install scripts).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry -> developer machine / CI | @11ty/eleventy-img and its native sharp/libvips binaries are downloaded and run at build time |
| committed image files -> sharp/libvips decoder | the build decodes image files from the repository |
| generated markup -> visitor browser | eleventy-img inserts every attribute except alt raw into the HTML |
