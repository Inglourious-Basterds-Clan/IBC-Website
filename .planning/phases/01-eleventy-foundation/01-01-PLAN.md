## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry -> developer machine / CI | Third-party package code (Eleventy, Lighthouse via npx) runs locally and in CI |
| env (shell / CI job) -> build | SITE_URL / PATH_PREFIX values flow into public HTML attributes |
| built HTML -> visitor browser | Outbound links opened with target="_blank" |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | test/helpers.js build env | low | mitigate | build() deletes SITE_URL, PATH_PREFIX, INCLUDE_DEV_PAGES, ELEVENTY_RUN_MODE from the inherited env before merging the variant env, so a CI job env cannot turn a "root" variant into a prefixed one and produce a false green |
| T-01-02 | Tampering | src/_data/site.js env read | low | accept | Values come from the repo-controlled workflow or the developer's own shell, never from visitors; Nunjucks autoescape encodes them in attributes |
